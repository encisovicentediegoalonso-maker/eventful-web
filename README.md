# Eventful Web

Sube todos estos archivos a tu repositorio de GitHub manteniendo las carpetas.

GitHub Pages:
Settings → Pages → Deploy from a branch → main → /(root) → Save.

Para cambiar WhatsApp, edita `js/script.js` y reemplaza `51999999999` por el número real, sin +, espacios ni guiones.

Reemplaza `images/evento-1.svg`, `evento-2.svg` y `evento-3.svg` por fotos reales de Eventful si deseas una galería real.
